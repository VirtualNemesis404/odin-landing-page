# Landing Page

A simple landing page built with HTML and CSS as part
of The Odin Project Foundations course.

## About the Project

This project was created to practice and apply the fundamental
HTML and CSS concepts learned throughout the Foundations course.

## Built With

- HTML5
- CSS3

## What I Learned

- Structuring web pages with HTML.
- Styling layouts using CSS.
- Working with the box model, spacing, and alignment.
- Using Flexbox to create page layouts.

## Getting Started

### Prerequisites

A modern web browser.

### Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
